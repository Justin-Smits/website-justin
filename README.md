# Smits Digital

Statische bedrijfswebsite met een blog en een GitHub-blogstudio.

Begin bij **START-HIER.md** voor installatie, toegangstoken en dagelijks gebruik.

- Website: https://smitsdigital.com/
- Blog: https://smitsdigital.com/blog/
- AI-diensten: https://smitsdigital.com/ai-agents.html
- Beheer: https://smitsdigital.com/admin/

De zip bevat de gebouwde pagina’s. Voor gewone publicatie zijn geen npm-afhankelijkheden nodig.

```bash
npm test
npm run build
```

Node.js 20+ is nodig voor bovenstaande ontwikkelcommando’s. Zie **OPLEVERING.md** voor testdekking en **SEO-EN-CONTENTPLAN.md** voor vervolgstappen.
