Je token blijft alleen in het geheugen van dit tabblad en wordt uitsluitend naar GitHub verstuurd. Na verversen log je opnieuw in.

Eerste keer? Zo maak je een toegangstoken
  1. Open GitHub → Fine-grained personal access token ↗.
  2. Kies jouw account als Resource owner, stel een vervaldatum in en selecteer alleen website-justin.
  3. Geef bij Repository permissions: Contents → Read and write. Metadata wordt automatisch toegevoegd.
  4. Genereer het token, bewaar het in je wachtwoordmanager en plak het hierboven. Zet het nooit in je openbare repository.

Upload eerst de volledige zipinhoud naar je repository. Je websitehost moet automatisch publiceren vanaf main. In START-HIER.md staat de installatie.
